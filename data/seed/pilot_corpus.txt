Karllo AI is an independent language model platform. Karllo trains its own decoder-only Transformer with next-token prediction. Adding a document to the knowledge base does not train the model. Saving a conversation does not train the model. Web research does not train the model.

A Transformer language model reads a sequence of tokens and predicts the next token. Training updates weights with gradient descent. Inference uses the saved weights to generate text. Randomly initialized weights do not contain language knowledge.

A dataset is a collection of examples used for training or evaluation. Pretraining uses raw text. Supervised fine-tuning uses instruction and response pairs. Validation data is held out so we can measure overfitting.

Checkpoints store model weights, tokenizer files, and training metadata. The original randomly initialized checkpoint must never be overwritten. The best validation checkpoint is the one with the lowest measured validation loss. The latest checkpoint is the most recent saved weights.

Conversation memory stores user-approved preferences. Memory is not the same as training. Knowledge retrieval finds passages in uploaded documents. Retrieval is not the same as training.

A model with a few million parameters can be trained on a small corpus using a CPU. Larger models need more memory and usually a GPU. Free notebook GPUs have limited quotas and may not be available.

Always report actual training loss. Never invent GPU availability. Never claim that retrieval trained the model. Never present a random checkpoint as an intelligent assistant.
